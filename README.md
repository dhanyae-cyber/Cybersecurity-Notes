# Cybersecurity Learning Path & Notes

Welcome! This repository contains my **personal cybersecurity notes, tutorials, and lab exercises**.  
The goal is to **track my learning journey** while creating a useful resource for others who are interested in cybersecurity.

## Learning Path

I’m following a structured learning path to cover:

1. **Basics of Cybersecurity**
   - Introduction to cybersecurity
   - Security principles
   - Common threats and vulnerabilities

2. **Network Security**
   - TCP/IP fundamentals
   - Firewalls and IDS/IPS
   - Network scanning tools (Nmap, Wireshark)

3. **Web Security**
   - OWASP Top 10 vulnerabilities
   - XSS, SQL Injection, CSRF
   - Web penetration testing techniques

4. **Tools & Labs**
   - Practical exercises using Burp Suite, Metasploit, and more
   - Personal lab projects for hands-on practice

5. **Advanced Topics (Future)**
   - Malware analysis
   - Cryptography
   - Cloud security
